# Notebook conventions

- `01-data-exploration` - Exploration of Ukrainian datasets, data quality checks, and prompt preparation.
- `02-knowledge-distillation` - Experiments with transferring knowledge from a larger teacher model to a smaller student model.
- `03-pruning-notebook` - Experiments with removing model weights and evaluating the effect on model performance.
- `04-quantization-intro` - Implementation and comparison of quantization methods, examining model quality and memory usage.
- `05-generalised-knowledge-distillation` - Experiments with generalised knowledge distillation using student-generated responses and teacher feedback.

The five notebooks in this folder are executed.
