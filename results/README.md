# results/

What's in here and how it got there:

| File | Written by | Contains |
|---|---|---|
| `metrics.json` | `python -m wine_origin evaluate` (single active model) or `python scripts/run_experiment.py` (full comparison — superset of what `evaluate` writes) | Whichever ran most recently — see below |
| `experiments.md` | `python scripts/run_experiment.py` | The experiment log: baseline + every model tried, including the rejected one |
| `figures/*.png` | `evaluate` / `run_experiment.py` | Confusion matrix plots |
| `demo/demo-wine.gif` | Recorded by hand (see `docs/recording-a-demo.md`) | Screen recording of the Streamlit app, embedded in the root README's Demo section |

**Why `metrics.json` is committed but `data/` and `models/` aren't:** it's a small JSON file (a few KB), and it's what makes the numbers in the root README's results table checkable without anyone having to rerun training first.

**A note on `metrics.json`'s shape:** `python -m wine_origin evaluate` (part of `make reproduce`) writes just the active model's numbers — accuracy, macro-F1, confusion matrix, CV stats, environment info. `scripts/run_experiment.py` writes a superset that also includes a `models` key comparing baseline / logistic regression / random forest / the rejected SVM run. Since both write to the same path, whichever command ran last is what's on disk — if you want the full comparison back after running `make reproduce`, just run `python scripts/run_experiment.py` again. The version committed to this repo was generated by `run_experiment.py`.

Every number here should be reproducible by running `make reproduce` (prints the primary metric) or `python scripts/run_experiment.py` (prints the full comparison) — if your local numbers don't match, check `metrics.json`'s `env` field for the versions and seed this was generated with.
